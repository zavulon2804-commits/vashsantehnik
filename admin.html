Для входа нужен ключ доступа GitHub. Он хранится только в этом браузере.

  1. Откройте создание ключа на GitHub
  2. Repository access: Only select repositories → vashsantehnik
  3. Permissions → Repository permissions → Contents: Read and write
  4. Нажмите Generate token и вставьте ключ ниже

Как пользоваться

Щёлкните по тексту на странице и правьте его прямо там.

Щёлкните по фото, чтобы заменить его. Фото сжимается автоматически.

Скрытые части (шаги квиза, меню на телефоне) правятся после кнопки «Показать скрытое».

После сохранения сайт обновляется за 1-2 минуты.
